# Mini Car Racing

A small browser-based car racing game built with HTML, CSS, and JavaScript.

## How to play

1. Open `index.html` in a web browser.
2. Select **Start Race** or press <kbd>Space</kbd>.
3. Use <kbd>←</kbd>/<kbd>→</kbd> or <kbd>A</kbd>/<kbd>D</kbd> to change lanes.
4. Dodge traffic for as long as possible to increase your score and speed.
